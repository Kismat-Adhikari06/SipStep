# SipStep

SipStep is a local-first Android activity and hydration tracker. It uses the phone's built-in `TYPE_STEP_COUNTER` sensor for steps, and supports water goals, reminders, and a local profile.

The step counter does not apply vehicle or motion-classification filters. Resetting the displayed count does not stop tracking.

Build and install from PowerShell with `.\gradlew.bat installDebug`.
